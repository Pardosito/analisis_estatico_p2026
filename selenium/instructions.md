# Instrucciones

Posicionarse en carpeta /features y desde allí correr:

```
behave features
```

Este comando ejecutará todos los .feature que se encuentren en la carpeta de /features (aunque ahorita solo hay uno jjj)

# Precondiciones

Corre el siguiente comando para instalar las librerías necesarias para correr este pequeño ejercicio

```
pip install -r requirements.txt
```
